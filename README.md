### [+] Description
Mango Cam jest to rozwiazanie do popularnych aplikacji jak DroidCam itp. ale dla linux, Jak narazie działa na systemie Android który posiada ADB. 

### [+] Installation
 - `sudo chmod +x mangocam.sh`
 - `bash mangocam.sh`

### [+] Usage
`./mangocam.sh`

### [+] Requirements
 - Android Device
 - ADB
 - Developer Options: ON
